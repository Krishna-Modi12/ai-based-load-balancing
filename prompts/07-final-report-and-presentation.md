# Antigravity Prompt 07 — Report and presentation from evidence

Read the report structure and research bibliography. Inspect the actual repository, test outputs, experiment exports, commit history and screenshots. Produce the final report and presentation from **verified project evidence only**.

Rules:
- Never invent experimental data, test counts, citations, signatures, screenshots, or team contributions.
- Clearly separate implemented features, partially implemented features, future work, and known limitations.
- Use a consistent IEEE-style reference format and verify bibliographic details/DOIs from authoritative sources.
- For every benchmark table/figure, record workload, hardware/software, request rate/concurrency, duration, repetitions, and policy configuration.
- Explain algorithms, architecture, database, API, ML features/model/training split/fallback, test strategy and threats to validity.
- Discuss negative or mixed findings honestly; do not claim AI is always better.
- Include a short user guide, reproducibility commands, and appendix of selected tests/API examples.
- Use the institution's required project-report format if supplied; otherwise follow `docs/09-final-report-structure.md`.

Before final output, cross-check all claims against source files or experiment artifacts. List unresolved placeholders and do not present the report as final until they are resolved by the team.
